### Finding 1: separate context

A visibly marked context field reduces the risk of passing a transcript guess off as the user’s own words, but **automatically adding it to the notes conflicts with the recorded rule that nothing is added that the user did not write**. A transcript-derived statement can also be wrong, incomplete, or connected to the wrong reaction. Restricting it to the last 20 seconds does not cure that ambiguity, especially given the observed timestamp drift.

The promise-consistent default is to keep “this” or “lol that” as the user wrote it, linked to the captured moment. If contextual help is wanted, it needs an explicit product decision: for example, a separately labeled, optional excerpt that the user can inspect and choose to include. The same boundary should apply to generated topic headings and exports, not just note text.
